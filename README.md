# Clinic EMR — ဆေးခန်းမှတ်တမ်း

ဆေးခန်းသုံး **လူနာမှတ်တမ်း + ဆေးညွှန်း + ပြန်လည်ပြသမှု + ရောင်းအားစာရင်း** web app
(မြန်မာ / English နှစ်ဘာသာ၊ ဖုန်းအတွက် အထူးပြုလုပ်ထား၊ offline ရသည်)

## ပါဝင်သည့်လုပ်ဆောင်ချက်များ

| အပိုင်း | ရှင်းလင်းချက် |
|---|---|
| 🧑‍⚕️ လူနာမှတ်တမ်း | မှတ်ပုံတင်၊ ရှာဖွေရန်၊ allergy / နာတာရှည် / လက်ရှိဆေး / ကိုယ်ဝန် / ကျောက်ကပ် မှတ်သားခြင်း |
| 🩺 လာရောက်မှုမှတ်တမ်း | history, စစ်ဆေးချက်, diagnosis, plan + **အတိုကောက် template** (ဥပမာ `htn` နှိပ်ရုံနှင့် သွေးတိုးပုံစံထည့်) |
| 💡 ဆေးညွှန်းအကြံပြုချက် | ရောဂါအမည်ပေါ်မူတည်၍ guideline ရင်းမြစ် (ADA, WHO…) နှင့်တကွ အကြံပေးခြင်း — **အကြံပြုချက်သာ** |
| 💊 ဆေးညွှန်း | ဆေးရွေးချယ် → ပမာဏ/အကြိမ်/ရက် → **စစ်ဆေးရန်** (allergy, ဆေးဓာတ်ပြုမှု, ကလေးအလေးချိန်အလိုက် mg/kg) → Print/PDF |
| 📅 ပြန်လည်ပြသမှု | နောက်ပြန်လာရမည့်ရက် သတ်မှတ် → ယနေ့ / ရက်လွန် စာရင်း dashboard |
| 💰 ငွေစာရင်း | တစ်ကြိမ်ချင်း စမ်းသပ်ခ + ဆေးဖိုး မှတ် → လချုပ် report (voucher မထုတ်) |
| 📊 ရောင်းအားဆန်းစစ်ချက် | အရောင်းရဆုံးဆေး (အရေ/ငွေ), ရောဂါအလိုက် ဆေးအုပ်စု, ၁၄ ရက်လမ်းကြောင်း |
| 💊 ဆေးဒေတာဘေ့စ် | အသုံးများဆေး **၁၇၇ မျိုး** ပါပြီး (ကလေးပမာဏ mg/kg အတိအကျ + **လုံးဝမသုံးသင့်သောအခြေအနေများ** + **သတိပြုရန်များ** နှင့်တကွ) + ကိုယ်တိုင်ထည့်/ပြင် + CSV import |
| 👥 အသုံးပြုသူ | ဆရာဝန် + တပည့် (အခန်းကဏ္ဍခွဲ) — ပထမဆုံးမှတ်ပုံတင်သူက ဆရာဝန်အလိုအလျောက်ဖြစ် |

## စတင်ရန် အဆင့် (၃) ဆင့်

### အဆင့် ၁ — Supabase တွင် SQL run ရန် (တစ်ကြိမ်တည်း)

1. [supabase.com/dashboard](https://supabase.com/dashboard) → မိမိ project (`hjcftfcfsbgqsinocugj`) ကို ဖွင့်ပါ
2. ဘယ်ဘက်မီနူး → **SQL Editor** → **New query**
3. `supabase-schema.sql` ဖိုင်ထဲက စာသားအကုန်လုံး ကူးထည့်ပြီး **Run** နှိပ်ပါ
   (table များ + လုံခြုံရေးစည်းမျဉ်း RLS များ တည်ဆောက်ပေးမည်)
4. **နောက် query အသစ်** ဖွင့်ပြီး `seed-drugs.sql` ထဲက စာသားအကုန်လုံး ကူးထည့်ပြီး **Run** နှိပ်ပါ
   (ဆေး ၁၇၇ မျိုး ထည့်သွင်းမည် — ပြန်ထပ်နှိပ်လည်း အန္တရာယ်မရှိ)

> ℹ️ **schema အဟောင်းကို run ပြီးသားသူများ:** `supabase-schema.sql` ကို ထပ်မံ run လိုက်ပါ —
> `contra` / `precautions` / `contra_keys` column အသစ်များ အလိုအလျောက် ထည့်ပေးမည်
> (`ADD COLUMN IF NOT EXISTS` ဖြင့် ဘေးကင်းသည်)။ ပြီးမှ `seed-drugs.sql` ကို run ပါ။

> ⚠️ **အီးမေးလ်အတည်ပြုခြင်း ပိတ်ရန်:** Dashboard → **Authentication** → **Providers** → **Email** →
> **Confirm email** ကို **OFF** ထားပါ (မဟုတ်ရင် အကောင့်ဖွင့်ပြီးတိုင်း အီးမေးလ်အတည်ပြုရမည်)။

### အဆင့် ၂ — Vercel တွင် deploy လုပ်ရန်

**နည်းလမ်း A — Vercel CLI (အလွယ်ဆုံး)**
```
cd clinic-app
npx vercel
```
မေးတာတွေ Enter နှိပ်သွားလိုက်ပါ — ပြီးရင် link ရမည် ✅

**နည်းလမ်း B — GitHub ကနေ**
1. `clinic-app` ဖိုဒါတစ်ခုလုံးကို GitHub repo အသစ်မှာ တင်ပါ
2. [vercel.com/new](https://vercel.com/new) → **Import** → repo ရွေးပါ
3. Build setting ဘာမှ ပြင်စရာမလို — **Deploy** နှိပ်လိုက်ပါ ✅

### အဆင့် ၃ — App ထဲတွင် ဆက်တင်ထည့်ရန် (တစ်ကြိမ်တည်း)

1. Deploy ရတဲ့ link ကို iPhone Safari မှာ ဖွင့်ပါ → **Setup** စာမျက်နှာ ပေါ်လာမည်
2. **Project URL:** `https://hjcftfcfsbgqsinocugj.supabase.co`
3. **anon public key:** Supabase Dashboard → **Settings** → **Data API** → **anon public** key ကို ကူးပြီး ကွက်လပ်မှာ ထည့်ပါ
   - ⚠️ **service_role (secret) key ကို မည်သူ့ကိုမှ မပေးပါနှင့်** — app မှာ မလိုပါ
4. ဆေးခန်းအမည် ထည့်ပြီး **စတင်မည်** နှိပ်ပါ
5. **အကောင့်ဖွင့်ရန်** → အမည်၊ အီးမေးလ်၊ စကားဝှက် ထည့်ပါ
   - ℹ️ **ပထမဆုံးမှတ်ပုံတင်သူက ဆရာဝန် (admin) အလိုအလျောက် ဖြစ်မည်**
   - တပည့်က နောက်မှ ကိုယ်တိုင် "အကောင့်ဖွင့်ရန်" နှိပ်ပြီး ဝင်နိုင်သည် (တပည့်အခန်းကဏ္ဍဖြင့်)

### iPhone မှာ app လို သုံးရန်
Safari → Share → **Add to Home Screen** — icon ပေါ်လာပြီး app လို ဖွင့်သုံးနိုင်သည်။

## အသုံးပြုသူ စီမံခန့်ခွဲမှု
- **ဆက်တင် → အသုံးပြုသူများ** (ဆရာဝန်သာ မြင်ရသည်): အခန်းကဏ္ဍ ပြောင်းနိုင်သည်
- တပည့်: လူနာမှတ်တမ်း ရေး/ကြည့် + ဆေးညွှန်းရေးနိုင်သည်
- တပည့် **မလုပ်**နိုင်တာ: ဆေးဒေတာ ပြင်/ဖျက်/ထည့်, လူနာမှတ်တမ်း ဖျက်

## အရေးကြီးမှတ်ချက်များ
- ⚠️ **ဤအက်ပ်သည် အကူအညီပေးစနစ်သာဖြစ်ပြီး ဆရာဝန်၏ ဆုံးဖြတ်ချက်ကို အစားမထိုးပါ။** သတိပေးချက်အားလုံး အကြံပြုချက်သာဖြစ်ပြီး override လုပ်နိုင်သည်။
- 💊 ဆေးဒေတာဘေ့စ်သည် အများပြည်သူရနိုင်သော ရင်းမြစ်များ (FDA labels, WHO EML ပုံစံ အသိပညာ) မှ စုစည်းထားခြင်းဖြစ်ပြီး MIMS / Oxford Handbook တို့မှ **ကူးယူထားခြင်းမဟုတ်**ပါ။ အရေးကြီးသော ကလေးဆေးပမာဏများကို အသုံးမပြုမီ ကိုယ်တိုင်စစ်ဆေးပါ။
- 📴 Internet မရှိလည်း သုံးနိုင်သည် — ဒေတာက ဖုန်းထဲမှာ သိမ်းထားပြီး online ပြန်ဖြစ်မှ server နှင့် sync လုပ်သည်။
- 🔄 Sync ကွဲလွဲမှု: နောက်ဆုံးပြင်သည့်အရာ အနိုင်ရသည် (last-write-wins)။
